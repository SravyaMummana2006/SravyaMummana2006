BIOTrace: Multimodal Media Authenticity

Biological Vital Signals & Forensic Ocular Kinematics

1. Problem Solved

Standard deepfake detectors inspect superficial facial pixels, making them fragile against modern diffusion generators and video compression artifacts.

2. Why I Built It

To engineer an evasion-resistant forensic detection system that measures human biological vitality—subcutaneous blood volume pulses and involuntary eye mechanics—which synthetic generators fail to reproduce coherently.

3. Technical Mechanism

Evaluated on the HiDF benchmark with bipartite actor isolation (zero identity overlap between 6,106 training and 1,308 test videos). Combines EfficientNet-B0 visual representations with rPPG CHROM & POS algorithms and Eye Aspect Ratio (EAR) kinematics. Features a decoupled Java 21 Swing Forensic Workstation with live JFreeChart pulse telemetry and a Python FastAPI inference backend.

4. Technologies Used
Java 21 LTS Python 3.11 PyTorch 2.6 FastAPI OpenCV MediaPipe SQLite JDBC
5. What Makes It Unique

Achieved 0.7952 ROC-AUC under strict Protocol C identity isolation, with 104 recovered visual failure cases and 344 automated test assertions.

SPEED_DEMON: High-Throughput Log Engine

Parallel Log Ingestion & Metrics Aggregation in Pure Rust

1. Problem Solved

Telemetry pipelines often suffer from memory bloat and thread contention when ingesting gigabytes of server logs.

2. Why I Built It

To explore how far low-level data alignment, scoped threading, and zero-allocation parsing in pure Rust can outpace traditional log parsers without pulling in heavyweight dependencies.

3. Technical Mechanism

Utilizes std::thread::scope for zero-overhead thread synchronization. Implements multithreaded chunk newline alignment, reusable 1 MiB streaming buffers per thread, custom byte-slice dictionary interning, and packed 64-bit composite keys ((hour_key << 32) | endpoint_id). Zero unsafe blocks.

4. Technologies Used
Rust 1.80+ std::thread::scope Streaming I/O Bitwise Packing Cargo LTO
5. What Makes It Unique

Parsed and aggregated 3.1 million log records (238 MB) in ~437 ms (1.81x speedup) on 12 logical cores, while keeping peak working set strictly below 270 MB.
