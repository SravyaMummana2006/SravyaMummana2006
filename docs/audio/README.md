# Audio Asset Licensing & Attribution Guide

This directory contains the audio track used by the interactive lo-fi music player in Sravya Mummana's portfolio.

## Track Information
- **File**: `romantic-lofi.mp3`
- **Style**: Romantic Lo-Fi / Downtempo Chillhop (ambient guitar chords, subtle vinyl crackle, warm bass, mellow percussion)
- **Duration**: ~2 minutes 18 seconds (4.22 MB)
- **Usage**: Personal developer portfolio interactive audio player

## Licensing & Public Hosting Checklist

Before pushing or redistributing audio tracks on public GitHub Pages or repositories, ensure the audio complies with one of the following licenses:

1. **Creative Commons CC0 (Public Domain)**: No attribution required; free for public hosting, streaming, and modification.
2. **Creative Commons Attribution (CC-BY 4.0 / CC-BY-SA)**: Requires crediting the original composer/artist and linking to the license in the player UI or footer.
3. **Royalty-Free Platforms (Pixabay, Free Music Archive, Incompetech, YouTube Audio Library)**: Ensure the platform license allows hosting on GitHub Pages / static CDN without copyright strike risks.
4. **Original Self-Composed Track**: You own 100% of the rights and can distribute under MIT or CC0.

> **Note**: The portfolio player is built with graceful fallbacks. If `romantic-lofi.mp3` is removed or blocked by `.gitignore`, the player automatically activates a gentle, synthesized Web Audio ambient generator so the music experience remains functional without copyright risks.
